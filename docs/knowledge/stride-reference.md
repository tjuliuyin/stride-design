# STRIDE 威胁分析知识库

> 供 `stride-threat-modeler` 子代理使用。包含 STRIDE 分类定义、各元素适用矩阵、常见威胁清单与标准缓解措施。

## STRIDE 六类威胁

| 类别 | 破坏的安全属性 | 核心问题 |
|---|---|---|
| **S**poofing 仿冒 | 真实性（Authentication） | 攻击者能否冒充其他用户/服务/设备？ |
| **T**ampering 篡改 | 完整性（Integrity） | 数据或代码能否被未授权修改？ |
| **R**epudiation 抵赖 | 不可否认性（Non-repudiation） | 操作者能否否认其行为且无法被证明？ |
| **I**nformation Disclosure 信息泄露 | 机密性（Confidentiality） | 信息是否会暴露给无权者？ |
| **D**enial of Service 拒绝服务 | 可用性（Availability） | 服务能否被耗尽或中断？ |
| **E**levation of Privilege 权限提升 | 授权（Authorization） | 低权限者能否获得更高权限？ |

## DFD 元素 × STRIDE 适用矩阵

| 元素 | S | T | R | I | D | E |
|---|---|---|---|---|---|---|
| 外部实体（用户/第三方） | ✅ | | ✅ | | | |
| 进程（服务/API） | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 数据存储 | | ✅ | ✅* | ✅ | ✅ | |
| 数据流 | | ✅ | | ✅ | ✅ | |

\* 日志类存储的篡改会间接导致抵赖。**跨信任边界的数据流和进程是分析重点。**

## 常见威胁与标准缓解措施

### Spoofing（仿冒）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 凭据猜测/撞库 | 强口令策略、泄露口令字典检查、登录失败锁定与速率限制、MFA |
| 会话劫持/固定 | 安全会话 ID（高熵随机）、登录后轮换会话、Cookie 设 Secure/HttpOnly/SameSite、会话超时 |
| 服务间仿冒 | mTLS 或服务账号 + 短期令牌（OIDC/JWT，校验 iss/aud/exp/签名）、禁止隐式信任内网来源 |
| 钓鱼/伪造端点 | TLS + 证书校验、HSTS、关键操作二次确认 |
| Token 伪造 | JWT 强制校验签名算法白名单（拒绝 none）、密钥轮换 |

### Tampering（篡改）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 传输中数据被改 | TLS 1.2+，禁用降级；消息级签名/HMAC（高敏场景） |
| 注入（SQL/NoSQL/命令/LDAP） | 参数化查询/ORM、输入白名单校验、最小权限数据库账号、禁用动态命令拼接 |
| 请求参数篡改（价格、ID、角色字段） | 服务端重新校验业务关键值、不信任客户端提交的权限/金额字段、对象级授权 |
| 存储数据被改 | 数据库访问控制、字段校验和/版本控制、关键记录审计 |
| 供应链/依赖篡改 | lockfile 固定版本、完整性校验（hash/签名）、SCA 扫描、可信源 |
| 反序列化攻击 | 避免反序列化不可信数据；必须时用安全格式（JSON）+ schema 校验 |

### Repudiation（抵赖）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 用户否认操作 | 审计日志记录 who/when/what/from-where/result，覆盖登录、敏感读写、配置变更 |
| 日志被删改 | 日志集中外送（append-only）、与业务系统隔离的写权限、完整性保护 |
| 时间不可信 | NTP 时钟同步、日志带可信时间戳 |
| 关键交易争议 | 数字签名/操作确认凭证、幂等键关联请求与结果 |

### Information Disclosure（信息泄露）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 传输窃听 | 全链路 TLS（含内部服务间）、HSTS |
| 存储泄露（拖库、备份泄露、对象存储误公开） | 静态加密、字段级加密（PII/凭据）、备份加密、存储桶默认私有 |
| 错误信息/调试泄露 | 统一错误响应（不含堆栈/SQL/路径）、生产禁用调试端点 |
| 越权读取（IDOR） | 对象级授权检查（每次按当前用户校验资源归属） |
| 日志/监控泄露敏感数据 | 日志脱敏（口令、token、PII）、监控数据访问控制 |
| 侧信道/枚举（用户名枚举、时序） | 统一响应文案与时延、注册/找回口令防枚举 |
| 缓存/CDN 泄露 | 私有数据禁缓存（Cache-Control: no-store）、缓存键含授权上下文 |

### Denial of Service（拒绝服务）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 请求洪泛 | 速率限制（IP/用户/接口多维度）、WAF、CDN/抗 DDoS |
| 资源耗尽（大包、慢速、复杂查询） | 请求体大小限制、超时、分页强制、查询复杂度限制、连接池上限 |
| 算法复杂度攻击（ReDoS、zip 炸弹） | 正则审查/超时、解压大小限制、上传文件类型与大小白名单 |
| 账号锁定被滥用（用锁定 DoS 他人） | 锁定与验证码组合、按 IP+账号联合限流 |
| 存储写满（日志/上传） | 配额、轮转、监控告警 |

### Elevation of Privilege（权限提升）
| 常见威胁 | 标准缓解措施 |
|---|---|
| 垂直越权（普通用户调管理接口） | 服务端按角色强制校验每个端点、默认拒绝、管理面隔离 |
| 水平越权（访问他人资源） | 对象级授权（资源归属校验） |
| 注入达成代码执行 | 同 Tampering 注入缓解 + 最小运行权限（容器非 root、只读文件系统） |
| 权限字段可被客户端指定（mass assignment） | DTO 白名单绑定、禁止直接绑定 role/isAdmin 等字段 |
| 配置错误（云 IAM 过宽、默认口令） | 最小权限 IAM、基线扫描、禁用默认凭据 |
| 提权链（SSRF→元数据服务） | SSRF 防护（出站白名单、禁内网地址）、IMDSv2 |

## 风险评级标准

风险 = 影响 × 可能性。

| 影响 | 定义 |
|---|---|
| 3 高 | 大量敏感数据泄露 / 资金损失 / 全局服务中断 / 完全接管 |
| 2 中 | 单用户数据泄露 / 部分功能受损 / 受限权限获取 |
| 1 低 | 信息价值低 / 影响范围极小 |

| 可能性 | 定义 |
|---|---|
| 3 高 | 无需特殊条件，公开工具即可利用 |
| 2 中 | 需一定前提（已有低权限账号、特定配置） |
| 1 低 | 需多个苛刻条件或内部访问 |

| 得分 | 等级 | 处置要求 |
|---|---|---|
| 6-9 | 高 | 必须消除或缓解，SPEC 中强制覆盖 |
| 3-4 | 中 | 应缓解，SPEC 中覆盖或记录接受理由 |
| 1-2 | 低 | 可接受，记录在案 |
